## 本次优化

- 思源黑体按中文字形拆分，模板常用字形仅需约 206 KB；英文与数字继续使用原字体。
- 精简字体范围声明，减少首屏样式体积。
- 三张封面预先压缩为 WebP，减少图片传输与运行时处理。
- 首屏主要文字直接显示，头像使用更短的入场动画。
- 关闭首页链接的自动路由预取，按实际访问加载页面。

日常启动和部署使用正常的 `npm run build` 与 `npm run start`，不需要额外性能开关。
